# ![Sort JSON logo](./public/favicon.png) Sort JSON

Simple Vite + React + TypeScript app that sorts JSON keys recursively and displays a formatted output.

![Screenshot](./screenshot.png)

## Run locally

```bash
yarn install
yarn run dev
```

## Run tests

```bash
yarn run test
```
